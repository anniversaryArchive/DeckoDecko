# 0005. 라인업 이미지는 공식 사이트 이미지 URL 을 그대로 쓴다

- 날짜: 2026-10-31
- 관련: #149, #216

## 상황

가챠 라인업(`gacha_items.image_link`)에 보일 사진이 필요하다. 기획서는 "앱 사진은 운영자가 직접 올린다"였지만, 팀이 가챠를 직접 사서 찍을 수 없다.
`tools/catalog-seed` 가 가져오는 공식 사이트(gashapon.jp)의 라인업 이미지는 반다이 CDN(`bandai-a.akamaihd.net`) 주소다.
이 이미지와 그 안의 캐릭터는 반다이 · 원작사의 저작물이다. 앱은 무료지만 허락 없이 쓰는 것은 같다.

## 선택지

| 선택지                                | 장점                               | 단점                                                               |
| ------------------------------------- | ---------------------------------- | ------------------------------------------------------------------ |
| 이미지 없이 이름 + 공식 페이지 링크   | 권리 문제가 거의 없다              | 라인업이 글자뿐이라 앱이 심심하다                                  |
| 사용자가 찍은 사진으로 채우기         | 팀이 찍지 않아도 쌓인다            | 처음엔 거의 비어 있다. 공개 동의 · 신고 처리가 필요하다            |
| 반다이에 사용 허락 문의               | 받으면 가장 깔끔하다               | 답이 늦거나 오지 않을 수 있어 출시 일정에 기댈 수 없다             |
| 공식 이미지를 Storage 로 복사해 쓰기  | 원본 주소가 바뀌어도 깨지지 않는다 | 복제본을 우리가 배포하게 된다. 복사 단계 · 저장 공간이 늘어난다    |
| 공식 이미지 URL 을 그대로 쓰기 (채택) | 바로 쓸 수 있고 추가 작업이 없다   | 권리자 신고 · 스토어 거절 위험. 원본 주소가 바뀌면 이미지가 깨진다 |

## 결정

- `gacha_items.image_link` 에 공식 사이트의 라인업 이미지 URL(반다이 CDN)을 그대로 넣고, dev · prod 모두 쓴다.
- 이미지를 우리 Storage 로 복사하지 않는다.
- 이미지가 보이는 화면에 출처를 표시하고, 권리자가 요청하면 바로 내린다.

## 이유

- 팀이 직접 찍을 수 없어서, 이미지가 있는 카탈로그를 출시에 맞추려면 공식 이미지밖에 없다.
- 라인업 사진은 상품을 알아보는 데 꼭 필요하다. 이름만으로는 어떤 아이템인지 알기 어렵다.
- 복사하지 않으면 추가 작업과 저장 공간이 들지 않고, 우리가 이미지 복제본을 들고 있지 않는다.

## 알아 둘 것

- 반다이가 주소를 바꾸거나 외부 연결을 막으면 라인업 이미지가 한꺼번에 깨진다. 팀이 감수하기로 했다. 그때 Storage 복사를 다시 검토한다.
- 권리자 신고나 App Store · Google Play 심사에서 지적되면 이미지를 내리고, 이 ADR 을 대체한다.
- 출처 표시와 "요청 시 내리는" 방법은 아직 없다. 따로 이슈로 진행한다.
